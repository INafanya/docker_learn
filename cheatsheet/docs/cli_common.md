## docker ps

```
docker ps
```
Показывает, какие контейнеры работают в данный момент. 


Показываются следующие поля: 
`CONTAINER ID` — уникальный идентификатор контейнера. Это короткий (обычно 12-символьный) хэш, который Docker использует для идентификации контейнера Идентификатор используется для выполнения различных команд с конкретным контейнером.
>Пример: 
`5ac1f0f42125` 


`IMAGE` — образ Docker, на основе которого был создан контейнер. Это имя и тег образа.
>Пример: 
`nginx:latest`, `ubuntu:20.04`


`COMMAND` — команда, которую контейнер выполняет сразу после запуска. Как правило, это команда, указанная в Dockerfile, или директива CMD, указанная при запуске контейнера.


`CREATED` — время, прошедшее с момента создания контейнера. Это поле отображает, как давно контейнер был создан.
>Пример: 
`2 hours ago` 
`5 minutes ago`


`STATUS` — состояние контейнера на данный момент. Это поле показывает, работает ли контейнер, когда он был запущен, а если не работает, когда он остановился.
>Пример: 
`Up 5 minutes`
`Exited (0) 2 hours ago`
`Restarting (1) 3 seconds ago`


`PORTS` — список сопоставленных портов между контейнером и хостом. Это поле показывает, какие порты контейнера проброшены на порты хоста.
>Пример:
`0.0.0.0:80->80/tcp`
Порт 80-го контейнера связан с портом 80-го хоста.


## docker ps -a
```
docker ps -a
```
То же, что и `docker ps`, но показывает все контейнеры, включая остановленные. 


## docker logs
*
```
docker logs <имя_или_id_контейнера_из_"docker ps">
```
Показывает логи контейнера. Один из основных инструментов для дебага сбоев или упавших приложений. 
>Пример: 
`docker logs 5ac1f0f42125`
## docker inspect


```
docker inspect <имя_или_id_контейнера>


```
Показывает всю информацию о контейнере: IP, подключенные тома, статус и другие. Полезна для дебага.
## docker top
```
docker top <имя_или_id_контейнера>
```
Показывает запущенные процессы в контейнере. Полезна для изучения процессов и команд, а также для дебага внутри запущенного контейнера.
