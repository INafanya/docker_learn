## Описание задания

Задание на на монтирование директориии в докер контейнер.

Монтирование директории бывает удобно, например для локальной разработки. При таком способе существенно облегчается редактирование и поддержка CheatSheet в сравнении с предыдущим методом, когда каждый раз при сборке приходилось подкладывать файлы конфигурации.

Работать будем с веткой cheetsheet. Для реализации монтирования директории будем использовать ключ -v

# Подсказка

```
docker run --rm -it -p 8000:8000 -v /mydir:/docs squidfunk/mkdocs-material
```
Измените /mydir на абсолютный путь к директории с cheatshet
