## Описание задания

Задание на подготовку базы данных к использованию в продуктивном окружении используя Docker.

Вам предоставили бекенд приложения, которое записывает данные в mongoDB.

# Обратите внимание. Уже реализован такой сценарий:

Есть mongoDB, которая работает для тестового окружения и запущена командой
```
docker run -d --network host mongo:7.0
```
Примечание параметр --network host оставляем без изменений, (данный параметр будет рассмотрен подробнее в модуле "Сеть в Docker")

Есть приложение, которое записывает данные в базу и выводит количество записей.

Сборка и запуск приложения
```
docker build -t write_app .
docker run  --network=host write_app
```
