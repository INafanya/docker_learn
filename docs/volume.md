# Тома (Volumes)

[Ссылка на курс](https://slurm.io/docker){ .md-button .md-button--primary }

## Хранение данных вне контейнера
`Пример:` база данных сохраняет данные в Volume, чтобы при перезапуске контейнера данные сохранялись.

`Преимущества:` независимость от хостовой файловой системы, простота резервного копирования.

`Недостатки:` менее прозрачно, чем bind mounts.

## Пример использования
```
docker volume create my-volume
```
Создаём том с именем "my-volume".
```
docker run -d -v my-volume:/app/data <имя_образа>
```
