# Что это?
Docker cheatsheet — это интерактивный сквозной проект, который позволит познакомиться с Docker, применяя новые знания по мере изучения. А еще это ваша личная база знаний, которую можно пополнять и совершенствовать на протяжении всего курса.

## Данный проект редактируется студентом на свое усмотрение. Данный репозиторий представлен в качестве точки, с которой можно начать или вернуться, если все потерялось.

# Как это работает?
Под капотом Docker cheatsheet - проект MkDocs, который преобразует файлы в формате MarkDown в веб-страницы, который можно запустить в контейнере. В итоге получится веб-портал, который запущен в докере и открывается через браузер, а внутри - навигация по темам, поиск и возможность редактирования информации "на лету".

`Используйте данный проект как основу для конспектов, редактируйте, добавляйте информацию по аналогии с созданными файлами, и в конце курса это будет полноценный справочник-конспект.`

По ходу курса мы пройдем путь от директории с текстовыми файлами, попутно созадим Dockerfile, познакомимся с методами хранения и увидим как Docker может быть полезен для подобного проекта.
