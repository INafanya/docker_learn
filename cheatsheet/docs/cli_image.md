# Работа с образами

[Ссылка на курс](https://slurm.io/docker){ .md-button .md-button--primary }

`Docker Image` — неизменяемый шаблон, который используется для создания контейнеров. Образ включает в себя все необходимые файлы, зависимости, настройки и инструкции для запуска приложения. Образы создаются на основе инструкций, записанных в Dockerfile.


## docker image ls
```
docker image ls
```
Показывает доступные (загруженные) образы.


## docker image inspect
```
docker image inspect <имя_образа>
```
Показывает больше информации об образе (теги, дату создания, размер, слои и так далее).


## docker image tag
```
docker image tag <имя_образа> <имя_нового_образа>
```
Переименовывает образ, присваивает тег. Используется, например, для задания собственного имени и тега образу, чтобы затем его загрузить в локальный регистри.


## docker image rm
```
docker image rm <имя_образа>
```
Удаляет образ.


## docker image pull
```
docker image pull <имя_образа>
```

Загружает образ `из` регистри.

## docker image push
```
docker image push <имя_образа>
```
Загружает образ `в` регистри.


## docker image prune
```
docker image prune
```
Удаляет неиспользуемые образы.
