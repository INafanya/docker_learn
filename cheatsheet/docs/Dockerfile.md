# Dockerfile


[Ссылка на курс](https://slurm.io/docker){ .md-button .md-button--primary }

`Dockerfile` — это текстовый файл, содержащий инструкции для создания Docker Image. Инструкции в Dockerfile включают различные директивы, необходимые для создания образа.


## Пример Dockerfile из презентации:
Dockerfile
```
# Указываем базовый образ
FROM python:3.9-slim
# Указываем рабочую директорию
WORKDIR /app
# Копируем программу
COPY app.py .
# Указываем команду для запуска
CMD ["python", "app.py"]
```


## Синтаксис
## FROM
Указывает базовый образ, от которого будет строиться новый образ.
## RUN
Выполняет команду в слое образа, устанавливая программы или выполняя другие настройки.
## WORKDIR
Устанавливает рабочую директорию для команд RUN, CMD, ENTRYPOINT, COPY и ADD.
## COPY
Копирует файлы и директории из контекста сборки в файловую систему образа. Слева путь до файла в локальной системе, справа — в Docker (указана точка, так как используется WORKDIR).
## CMD
Определяет команду, которая будет выполнена при запуске контейнера. В отличие от ENTRYPOINT, CMD может быть переопределён при запуске контейнера.
