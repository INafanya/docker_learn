# Работа с контейнерами


[Ссылка на курс](https://slurm.io/docker){ .md-button .md-button--primary }


`Docker Container` — запущенный экземпляр Docker Image. Контейнеры представляют собой изолированные среды выполнения, которые содержат всё необходимое для работы приложения. Контейнеры могут быть созданы, запущены, остановлены, перемещены или удалены с использованием Docker CLI или API.


## docker container run
```
docker container run <имя_образа>
```
Создаёт и запускает контейнер из образа. 
Чаще используется сокращение docker run <имя_образа>, имеющее такой же функционал, `здесь и далее` в командах используется такой же принцип.
```
docker run <имя_образа>
```

## docker logs
```
docker container logs <имя_или id_контейнера>
```
Показывает логи работающего контейнера. Полезна для дебага ошибок и проверки работы приложения.

## docker cp

Копирует файлы и директории из контейнера в локальную файловую систему и наоборот.
```
docker cp ./мой_файл.txt <имя_или id_контейнера>:/work
```
Копирует файл `в` контейнер из локальной файловой системы.
```
docker cp <имя_или id_контейнера>:/var/logs/ /tmp/app_logs
```
Копирует директорию `из` контейнера в локальную файловую систему.


## docker attach
```
docker attach <имя_или id_контейнера>
```
Подключается к работающему контейнеру и выводит потоки ввода, вывода и ошибок.


## docker inspect
```
docker inspect <имя_или id_контейнера>
```
Показывает больше информации о контейнере (IP, порты, тома и так далее).


## docker container prune
```
docker container prune
```
Удаляет все остановленные контейнеры.
>Осторожно! Можно удалить данные, если не используются тома или bind mount.


## docker restart 
```
docker restart <имя_или id_контейнера>
```
Перезапускает контейнер.


## docker rm 
```
docker rm <имя_или id_контейнера>
```
Удаляет контейнер.
>Осторожно! Можно удалить данные, если не используются тома или bind mount.


## docker stats
```
docker stats <имя_или id_контейнера>
```
Показывает статистику использования ресурсов для контейнера по `CPU`, `RAM`, `NET I/O`, `BLOCK I/O`.


## docker container top
```
docker top <имя_или id_контейнера>
```
Выводит список запущенных процессов в контейнере.


docker container exec Execute a command in a running container
docker container ls List containers


## docker image inspect
```
docker image inspect <имя_образа>
```
Показывает больше информации об образе (теги, дату создания, размер, слои и так далее).


## docker image tag
```
docker image tag <имя_образа> <имя_нового_образа>
```
Переименовывает образ, присваивает тег. Используется для
Create a tag TARGET_IMAGE that refers to SOURCE_IMAGE.


## docker image rm
```
docker image rm <имя_образа>
```
Удаляет образ.


## docker image pull
```
docker image pull <имя_образа>
```


Загружает образ `из` регистри.


## docker image push
```
docker image push <имя_образа>
```
Загружает образ `в` регистри.


## docker image prune
```
docker image prune
```
Удаляет неиспользуемые образы.
