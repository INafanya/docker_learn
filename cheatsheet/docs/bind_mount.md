# Проброс директорий (Bind mounts)
[Ссылка на курс](https://slurm.io/docker){ .md-button .md-button--primary }

## Связывают директорию на хосте с контейнером
`Пример:` приложение обращается к конфигурационному файлу на хосте (например, в той же директории) через bind mount.

`Преимущества:` доступ к любой директории на хосте.

`Недостатки:` возможны проблемы с безопасностью и совместимостью.

## Пример использования
```
docker run -d -v /path/on/host:/app/config <имя_образа>
```
